E-Paper Display
Waveshare E-Paper Display (optional, not certified)

This is an optional, supplemental status surface only - never a moving map, artificial horizon, traffic scope, ForeFlight/EFB substitute, safety-critical annunciator, or weather source. It is not a certified flight instrument. Whether this display is enabled, connected, or working has no effect on 978 UAT / 1090 ES reception, GDL90 output, AHRS, GPS, or any other Stratux function - see Readiness for those.

Disabled by default. Supported hardware: Waveshare 3.7" e-Paper panel (SSD1677 controller, 480×280) on the Waveshare E-Paper Driver HAT Rev2.3, connected by its 9-wire harness - never mounted directly on the Pi's 40-pin header, which the AHRS board already occupies. See docs/waveshare-epaper-display.md in the Stratux repository for the full installation procedure, GPIO ownership audit, and troubleshooting guide.

Validated Wiring (do not power on while connecting)

Power the Pi down completely and disconnect it before connecting or changing any wire. Never move a wire while powered. This mapping was derived from an audit of every GPIO this project's own software and device-tree configuration claims on a Raspberry Pi 4B with a Stratux AHRS v2.0 board installed; it deliberately avoids physical pins 1 and 6, which that board covers. Connect the Driver HAT to the Pi only through its own 9-wire harness - never mounted directly on the 40-pin header.
