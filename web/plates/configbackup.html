Backup
Configuration Backup and Restore

Backs up and restores supported Stratux application settings only: radio enablement, alert thresholds, calibration profiles, and similar configuration. It is not a full SD-card backup and does not include:

  • Wi-Fi credentials, SSH keys, or any other secret/credential
  • Recordings or diagnostic bundles
  • Operating-system, network, or boot configuration

Restoring a calibration profile only makes sense if the physical AHRS mounting orientation matches the one it was captured for. Applying a profile made for a different mounting will make AHRS attitude (pitch/roll) incorrect. Some settings changes may require a restart to take effect.
