Wi-Fi Administration

Changing Wi-Fi settings can disconnect this device from the Stratux. Review the preview below carefully, and be ready to reconnect to the new network name if it changes. If you do not confirm within the time shown, this change is automatically undone and the previous, working configuration is restored.

This page does not provide remote/cloud administration and does not add a new security capability beyond what your device's existing Wi-Fi mode already provides - a password only means clients need it to join, not that traffic is otherwise protected. Wi-Fi client presence (shown below) never proves a specific app like ForeFlight is connected, only that some device is.
