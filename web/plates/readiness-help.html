The Readiness page is a single-glance summary of every monitored subsystem, aimed at the same kind of overview a dedicated Sentry-class ADS-B receiver provides. It is not a flight-readiness certification - Stratux remains supplemental, non-certified situational-awareness equipment.

Each tile shows one of five states:

  • READY (green) - affirmative evidence the component is working right now.
  • DEGRADED (amber) - partially working, or something needs attention.
  • NOT_READY (red) - a confirmed failure or unavailable component.
  • NOT_INSTALLED (gray) - the hardware or feature is intentionally absent from this build, e.g. the AHRS board before it is installed, or a receiver band you have disabled in Settings. This is not a failure.
  • UNKNOWN (gray) - health has not yet been determined, e.g. immediately after startup.

A red or amber badge is never shown solely because no aircraft or FIS-B tower is currently in range - that is expected and shows as READY with an explanatory note, not a fault.

  • 978 UAT / 1090 ES mirror the receiver status also shown on the Status page, plus frame totals, current message rate, and (for 978) FIS-B tower count.
  • GPS distinguishes a device that is present but has not resolved a fix yet (amber) from a genuinely missing/unresponsive device (red).
  • Time shows the trusted-time synchronization state. Stratux has no real-time clock, so it must synchronize from GNSS (offline) or the network before recording can be trusted; "Recording permitted" reflects that gate directly.
  • Persistent Storage is the dedicated application-data partition (recordings, diagnostics, exports) - not the 250 MiB protected temporary overlay, which is shown separately and is expected to run at higher utilization by design.
  • AHRS, Barometer, and Fan Controller read NOT_INSTALLED until that physical hardware/integration exists; no attitude, pressure-altitude, or g-load values are ever implied while gray.
